# Rajeswari Portfolio

A responsive single-page professional portfolio created from the uploaded resume and M.Tech AIE portfolio/skills document.

## Files
- `index.html` — portfolio content and sections
- `style.css` — responsive styling
- `script.js` — mobile navigation

## Run locally
Open `index.html` in a browser.

## Publish
This static site can be published using GitHub Pages, Netlify, or another static hosting service.

## Source basis
The content is based on the uploaded resume and the uploaded M.Tech AIE portfolio/skills presentation. Personal family contact details from the academic presentation were intentionally not included in the public portfolio.
